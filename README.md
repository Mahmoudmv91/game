# باغ رویا — Dream Garden

نمونه اولیه یک بازی مستقل جورچین و بازسازی باغ، برای محمود.

**پیش‌نمایش قابل‌بازی:** https://dream-garden-mahmoud.mahmoudmv70.chatgpt.site

لینک بالا پیاده‌سازی وب با JavaScript است. کد Flutter در ریشه همین پروژه قرار دارد و پیاده‌سازی جداگانه‌ای است. نسخه Flutter در محیط ساخت فعلی اجرا یا کامپایل نشده؛ خروجی APK هنوز تولید نشده است.

## امکانات

- صفحه ۷×۷، پنج نوع مهره، جابه‌جایی معتبر، سقوط و ترکیب زنجیره‌ای.
- ۲۰ تنظیم مرحله، بمب و تقویت‌کننده رنگی.
- چمن و خاک دولایه در مراحل بعدی.
- ستاره، سکه، پنج مأموریت باغ و سه انتخاب دکور برای هرکدام.
- راهنما، بیلچه، ترکیب دوباره و ذخیره محلی پیشرفت.
- رابط فارسی و واکنش‌گرا.

دکورها فعلاً لایه‌های تصویری ساده‌اند. پیشرفت تکمیل‌شده و پاداش‌ها ذخیره می‌شوند؛ صفحه نیمه‌تمام با بارگذاری مجدد از نو آغاز می‌شود. تصاویر باغ و طراحی مهره‌ها برای این نمونه تولید شده‌اند و از بازی Gardenscapes استخراج نشده‌اند.

## اجرای Flutter

Flutter و ابزار پلتفرم هدف را نصب کن. سپس در یک پوشه جدید:

```sh
flutter create --platforms=android,ios,web --project-name=dream_garden dream_garden_run
```

فایل‌های `pubspec.yaml` و `analysis_options.yaml` و پوشه‌های `lib`، `assets` و `test` این پروژه را در پروژه ساخته‌شده جایگزین کن. تست پیش‌فرض `test/widget_test.dart` را حذف کن، سپس:

```sh
flutter pub get
dart format lib test
flutter analyze
flutter test
flutter run
```

برای iOS به macOS و Xcode نیاز است. وابستگی‌های برنامه فقط Flutter و `shared_preferences` هستند. موتور قوانین در `lib/game_engine.dart` مستقل از رابط کاربری است؛ رندر نسخه فعلی با ویجت‌های Flutter انجام می‌شود.

## تست و خروجی خودکار

فایل `.github/workflows/flutter.yml` برای اجرا روی GitHub Actions آماده شده است. پس از دسترسی نوشتن و قرارگرفتن در مخزن، روی Pull Request و شاخه اصلی اجرا می‌شود: تست موتور وب، نصب Flutter رسمی، تحلیل و تست Dart، ساخت APK آزمایشی و ساخت Flutter Web. فایل‌های خروجی از Artifacts همان اجرا دریافت می‌شوند.

این workflow هنوز در مخزن اجرا نشده است. اولین اجرا ممکن است نیاز به اصلاح سازگاری با نسخه stable روز Flutter و ابزار Android داشته باشد.

## پیش‌نمایش وب

پوشه `preview/` را با یک وب‌سرور استاتیک باز کن. بدون build و بدون سرور برنامه اجرا می‌شود.

```sh
node --test preview/tests/engine.test.mjs
node --check preview/app.mjs
python -m http.server 8080 --directory preview
```

۸ تست منطق وب پاس شده‌اند. مسیر برد مرحله اول، دریافت ستاره، انتخاب دکور، خرج ستاره و ذخیره پس از reload در مرورگر بررسی شده‌اند. رابط در عرض ۳۹۰ پیکسل هم بررسی شده است. جزئیات و محدودیت‌ها در `QA.md` آمده‌اند.
