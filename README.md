# باغ فیروزه — قصه ترنج

نمونه قابل بازی با **Flutter + Flame** برای موبایل و وب. گرافیک باغ ایرانی و شخصیت ترنج اختصاصی‌اند.

## امکانات نسخه ۰٫۲

- ۲۰ مرحله جورچین ۷×۷، حرکت محدود، هدف جمع‌آوری و لایه‌های خاک؛ سقوط و ترکیب‌های زنجیره‌ای.
- ترقه، بمب، دینامیت، شارژ گوی رنگین‌کمان، چکش، جابه‌جایی و راهنما.
- رشته آذرخش: انتخاب چند مهره هم‌رنگ، اتصال‌های برقی متحرک و حذف گروهی؛ یک تقویت‌کننده محدود در کنار مکانیزم اصلی جابه‌جایی.
- رندر و حلقه بازی با Flame؛ موج انفجار، ذرات، لرزش، نور و حرکت نرم مهره‌ها.
- ۱۲ صدای اختصاصی و موسیقی پس‌زمینه با flame_audio؛ دکمه صدا برای فعال‌سازی موسیقی.
- داستان فارسی با ترنج، پنج کار بازسازی با سه انتخاب برای هر کار، صندوقچه خوش‌آمد و جایزه هر سه برد.
- جان با بازگشت ۳۰ دقیقه‌ای، سکه، ستاره، ذخیره پیشرفت محلی و فونت فارسی همراه برنامه.

## اجرا

Flutter stable و Android SDK را نصب کنید. پوشه‌های پلتفرم با دستور زیر ساخته می‌شوند؛ کد پروژه حفظ می‌شود:

```sh
flutter create --platforms=android,web --project-name=dream_garden .
flutter pub get
flutter run
```

```sh
flutter analyze
flutter test
flutter build apk --release --split-per-abi
flutter build web --release --base-href /flutter/ --no-web-resources-cdn
```

GitHub Actions همین مراحل را در پروژه موقت اجرا می‌کند و سه APK آزمایشی جدا برای arm64-v8a، armeabi-v7a و x86_64 و خروجی Flutter Web را به‌عنوان artifact تحویل می‌دهد. برای نصب نسخه عمومی فروشگاه، امضای انتشار، آیکون نهایی و آزمون روی دستگاه‌های هدف لازم است. نسخه فعلی نمونه بازی است؛ خرید درون‌برنامه‌ای، حساب آنلاین و همگام‌سازی ابری ندارد.

## ساختار

`lib/game_engine.dart`: قوانین مستقل از رندر، `persian_board.dart`: Flame و افکت‌ها، `garden_controller.dart`: اقتصاد و ذخیره، `main.dart`: رابط فارسی و داستان. `scripts/generate_audio.py` صداهای اصلی را بازتولید می‌کند. مجوز فونت در `assets/fonts/LICENSE.txt` است.

`preview/` پیش‌نمایش قدیمی JavaScript است؛ نسخه Flutter جدید از خروجی `build/web` اجرا می‌شود.
